Sunset Vice Atelier turns 1–3 of your own photos plus a caption into GTA-style multi-panel cover art and exports it as a PNG in post sizes. Four layouts (Hero Trio, Split Sunset, Quad, Solo Poster), four colour grades (Vice Sunset, Neon Nights, Golden Hour, Mono Noir), huge tilted caption lettering, and one-click export at 1080×1080, 1080×1350, or 1920×1080. Photos are cropped and positioned per panel with drag-to-pan and a zoom slider, and the whole state lives in the URL so any cover is reproducible from a link. Fully offline — no uploads, no external requests, no Rockstar artwork or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — load photos, pick a layout and grade, type a caption, and hit Export PNG.
